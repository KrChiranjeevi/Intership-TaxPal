# TaxPal Full-Stack Application (`mean-app`)

This directory contains the source code for the **TaxPal** full-stack web application:

- **[`client/`](./client/)**: Angular 20 frontend SPA with Material components and Chart.js analytics.
- **[`server/`](./server/)**: Node.js + Express 5 + TypeScript backend with Prisma ORM and PostgreSQL.
- **[`api/`](./api/)**: Serverless entry point for Vercel deployment (`api/index.ts`).
- **[`vercel.json`](./vercel.json)**: Full-stack monorepo deployment routing configuration.

For complete project documentation, architecture diagrams, technology stack details, and setup instructions, refer to the [Root README](../README.md).
