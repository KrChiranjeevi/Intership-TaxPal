SECURITY & PRIVACY

Your financial data deserves protection.

Designed with defense-in-depth security principles to keep your records isolated and protected.

🔐

Dual-Token JWT Authentication

Short-lived 15-minute access tokens paired with 7-day refresh tokens hashed with SHA-256 in PostgreSQL.

🛡️

Multi-Tenant Ownership Isolation

Every single database query strictly filters by authenticated user ID, preventing unauthorized cross-user access.

📁

Protected Report Downloads

Generated PDF and CSV statements are streamed exclusively after verifying authenticated ownership.

⚙️

Defense in Depth

Protected by Helmet HTTP headers, 1MB body parser payload limits, and sanitized production error handling.
